# Phase 09 — MY 페이지 · 회차 이력 · 전체 이력 분석

> 선행: [07-portfolio-step3.md](07-portfolio-step3.md)
> 톤: **Warm · Orange** (`data-theme="warm"`) — 회고·격려 맥락
> 프롬프트 11번

---

## 1. 요구 정리

원문: *"Portfolio 분석의 몇 단계에 내가 와있는지, 점수는 얼마인지, 1·2·3단계를 한 번에 보여주는 화면. 1회만 했을 때는 한 페이지, 여러 번 했을 때는 카드 타입, n회 이상이면 전체 이력 분석 버튼 활성화."*

→ 회차 수(`attempts.length`)에 따라 **3가지 레이아웃**으로 분기한다.

| 회차 | 레이아웃 | 이력 분석 버튼 |
|---|---|---|
| 0회 | 빈 상태 | — |
| 1회 | **단일 상세 뷰** (전체 폭 1페이지) | 비활성 |
| 2회 | **카드 그리드** | 비활성 (`1회 더 하면 열립니다`) |
| 3회 이상 | **카드 그리드** | **활성** → `/my/history` |

`HISTORY_UNLOCK_THRESHOLD = 3` — `src/data/config.ts` 한 곳에서 관리 ([00 §3 Q5](00-overview.md)).

## 2. 공통 헤드

```
MY PORTFOLIO                                    ← --t-label
{이름}님의 포트폴리오 기록                          ← --t-kr-2
총 3회 분석 · 최고 91점 · 최근 2026. 8. 9.
                                    [ 새 분석 시작 ]
```

이름은 가장 최근 `mentorRequest.name`. 없으면 "게스트".

## 3. 0회 — 빈 상태

디자인 시스템 §"빈 상태엔 일러스트 대신 큰 활자와 색면".

```
00                              ← --t-display-3, --mute
아직 분석한 포트폴리오가 없습니다      ← --t-kr-3
첫 분석은 90초면 끝납니다
[ 포트폴리오 분석 시작하기 ]
```

배경 `--tint` 색면 블록. 이미지 없음.

## 4. 1회 — 단일 상세 뷰

원문의 *"1·2·3단계를 한 번에 보여줄 수 있는 화면"* 을 그대로 구현한다.

```
┌─── 진행 상태 ────────────────────────────────────────┐
│ ①AI 분석 ✓완료 ── ②멘토 검증 ●진행중 ── ③리포트 ○대기  │
└──────────────────────────────────────────────────┘

┌─ ① AI 분석 ──────────┐ ┌─ ② 멘토 검증 ──────┐ ┌─ ③ 통합 리포트 ─┐
│ 총점 87 / Grade A     │ │ 4/6 단계 진행 중     │ │ 잠김            │
│ 10원칙 미니 바        │ │ 현재: 2차 리뷰       │ │ 멘토 검증 완료 후 │
│ 상위3 / 하위3         │ │ 예상 완료 1분 후     │ │ 열립니다         │
│ [1단계 자세히]        │ │ [모니터 보기]        │ │                │
└──────────────────────┘ └────────────────────┘ └────────────────┘
```

- 3개 카드 가로 배열(데스크톱) / 세로 스택(모바일)
- 미도달 단계는 `--mute` + 잠금 상태 명시. **잠긴 카드도 무엇이 열릴지 보여준다** (동기 유지)
- 각 카드는 해당 라우트로 딥링크
- 2단계 진행 중이면 이 화면에서도 **실시간 갱신** ([06 §3.3](06-portfolio-step2.md) 절대 시각 재계산 재사용)

## 5. 2회 이상 — 카드 그리드

3-up / 2-up / 1-up. 최신 회차가 좌상단.

**회차 카드**
```
┌──────────────────────────┐
│ [프리뷰 썸네일 16:10]      │
│ #03  2026. 8. 9.          │
│ 커머스 앱 리디자인          │  ← 주제 (미제출이면 파일명)
│ 87 → Grade A              │
│ ●●● 3단계 완료             │  ← 단계 도트
│ 최고 기록 배지 (해당 시)     │
└──────────────────────────┘
```

- 호버: 이미지 `scale(1.03)` **하나만** ([03 §2.3](03-layout-navigation.md))
- 진행 중 회차는 상단에 `--primary` 6px ProgressBar
- 카드 클릭 → 해당 회차의 단일 상세 뷰 (`/my?attempt={id}`)
- 카드 우상단 `⋯` 메뉴: 리포트 다운로드 / 삭제(확인 모달)
- 정렬: 최신순(기본) / 점수순

## 6. `/my/history` — 전체 이력 분석 ★

3회 이상일 때만 접근 가능. 원문: *"n회 했던 포트폴리오 이력을 참고해서 얼마만큼의 점수 변화가 있었는지 상세하게."*

### 6.1 구성

**① 성장 요약**
```
FIRST 72  →  LATEST 91        +19점
평균 상승 +6.3점 / 회차
```
`+19` 를 `--t-impact`(700) — **이 페이지 유일한 700**. 하락 시 `--mute` 로 표기하고 문구를 조정한다("이번엔 아쉬웠지만" 류의 격려 없이 사실만).

**② 총점 추이 라인 차트**
- 순수 SVG로 직접 그린다 (차트 라이브러리 미도입 — 이 한 화면을 위해 번들을 늘리지 않는다)
- 격자·그라디언트 없음, 단색 선 `--primary` + 회차 노드
- 노드 호버/포커스 시 해당 회차 요약 표시
- 세로축은 0–100 고정 (자동 스케일은 변화를 과장한다)
- 모바일: 세로형 전환 (디자인 시스템 §Responsive "차트는 모바일에서 세로형으로")

**③ 원칙별 변화표**
10개 원칙 × 회차 매트릭스. 각 셀은 점수 + 첫 회차 대비 증감.

| 원칙 | 1회 | 2회 | 3회 | 변화 |
|---|---|---|---|---|
| 시각적 위계 | 7 | 8 | 9 | **+2** |
| 레이아웃·그리드 | 5 | 5 | 6 | +1 |
| … | | | | |

- 증감 정렬 토글. 가장 많이 오른 3개 / 정체된 3개를 상단에 별도 요약
- 모바일: 원칙별 카드 스택 + 스파크라인

**④ 해석 코멘트 (규칙 기반)**
LLM 없이 **결정론적 규칙**으로 생성한다. 근거 없는 서술을 만들지 않기 위함.

```
"가장 크게 오른 항목은 시각적 위계(+2)입니다."
"3회 내내 6점 이하에 머문 항목은 레이아웃·그리드입니다. 다음 회차의 최우선 개선 대상입니다."
"멘토 점수와 AI 점수의 격차가 8점 → 3점으로 좁혀졌습니다."
```

**⑤ 멘토 코멘트 아카이브**
회차별 멘토 종합 코멘트를 시간순 타임라인으로. 같은 지적이 반복되면 "반복 지적" 배지.

**⑥ 액션**
`[ 전체 이력 리포트 HTML 다운로드 ]` — [07 §6](07-portfolio-step3.md) `buildReportHtml` 을 이력 버전으로 확장 (`buildHistoryHtml`). 동일한 인라인·이스케이프 원칙 적용.

### 6.2 엣지 케이스

| 상황 | 처리 |
|---|---|
| 3회 중 1회가 미완료(2단계 진행 중) | **완료 회차만** 추이에 포함. "완료 2회 기준" 명시 |
| 점수가 동일 | "변화 없음" 표기, 증감 화살표 미표시 |
| 회차 삭제로 3회 미만이 됨 | `/my` 로 리다이렉트 + 안내 |
| 회차 20개 초과 | 차트는 최근 12회만, 표는 전체 스크롤 |

## 7. 완료 기준

- [ ] 0 / 1 / 2 / 3회 **4가지 상태** 전부 정확히 분기 (스토어 시딩으로 검증)
- [ ] 1회 뷰에서 1·2·3단계가 한 화면에 보이고 현재 단계가 명확
- [ ] 2단계 진행 중 회차가 MY에서도 실시간 갱신
- [ ] 3회 도달 시 이력 분석 버튼 활성, 2회에서는 남은 횟수 안내
- [ ] `/my/history` 직접 진입 시 3회 미만이면 `/my` 로 리다이렉트
- [ ] 라인 차트가 SVG로 렌더, 다크 모드·모바일 세로형 정상
- [ ] 원칙별 변화표 증감 계산 정확 (Vitest 검증)
- [ ] 해석 코멘트가 실제 데이터와 모순되지 않음 (규칙 기반 단위 테스트)
- [ ] 미완료 회차 혼재 시 "완료 N회 기준" 명시
- [ ] 회차 삭제 시 확인 모달 + 되돌릴 수 없음 안내
- [ ] Warm·Orange 세트 단독 사용
