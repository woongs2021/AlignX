# A. `/alignx` — AlignX AI

톤: **Cool · Mint** (`data-theme="mint"`) — 모델·기술 맥락

## A1. 히어로

프롬프트 10번: *"seed-design.io 메인페이지와 같이 영상으로 보여줄 예정. 일단은 AlignX 폴더의 svg 로고만 이미지로."*

**현재 영상 에셋이 없으므로** 로고 SVG 기반 모션 히어로로 만들고, 영상이 준비되면 교체할 수 있게 슬롯을 남긴다 ([00 §3 Q7](00-overview.md)).

```tsx
<HeroMedia
  video={null}                  // ← 나중에 'media/alignx.mp4' 지정하면 자동 교체
  fallback={<AlignxLogoMotion />}
/>
```

**`AlignxLogoMotion` 사양**
- `AlignX-logo.svg` 를 인라인 컴포넌트로 변환, `fill="currentColor"` (다크 대응)
- 진입 시 path `stroke-dasharray` 드로잉 1.2s → fill 페이드 400ms
- 이후 로고 뒤에서 `--soft` 색면 블록 3개가 아주 느리게(12s 루프) 어긋나며 지나감 — **그라디언트 대신 색면 이동**으로 깊이를 만든다 (디자인 시스템 §Don't 그라디언트 금지)
- `prefers-reduced-motion` → 정적 로고

**헤드라인**
```
ALIGNX AI                                       ← --t-label
포트폴리오를 읽는 10개의 눈                        ← --t-kr-1
사람이 좋은 포트폴리오를 알아보는 기준을
10개 축으로 분해해 정량화하는 분석 모델입니다.        ← --t-lead
```

**영상 교체 가이드:** `public/media/` 에 mp4 배치 → `HeroMedia` props 지정. `poster` 이미지 필수, `muted playsinline loop autoplay`, 모바일에서는 데이터 절약을 위해 `poster` 만 표시하고 탭 시 재생.

## A2. 본문 섹션 (더미 상세 설명)

우측 sticky 목차 ([03 §3.3](03-layout-navigation.md)) 와 함께 스크롤.

| # | 섹션 | 내용 |
|---|---|---|
| 1 | WHY — 왜 만들었나 | 포트폴리오 피드백이 "느낌"에 의존하는 문제. 같은 포트폴리오를 두 심사자가 정반대로 평가하는 현실 |

각 섹션: 영문 라벨 + 한글 제목 더블 라인 + 본문(68ch) + 썸네일 1장(`alignx-model` 키).

## A3. 한계 고지 (필수 섹션)

MVP 점수는 **더미 생성기 출력**이다. 실제 모델이 아니다. 이를 숨기면 사용자가 점수를 실제 평가로 오인한다.

페이지에 명시할 문구:
> 현재 공개된 분석 점수는 데모용 시뮬레이션 결과이며, 실제 AlignX 모델의 추론 결과가 아닙니다. 모델 연동은 준비 중입니다.

`badge-warning` + `--tint` 배경 노트 블록으로 배치. 1단계 결과 화면 하단에도 동일 문구를 축약해 넣는다.

## B2. FAQ 문항 (더미)

1. 분석 결과는 얼마나 정확한가요? → 현재 데모 시뮬레이션임을 명시
2. 어떤 파일을 올릴 수 있나요? → PDF · PNG · JPEG · GIF, 50MB 이하
3. 제 포트폴리오는 어디에 저장되나요? → **브라우저 로컬에만. 서버 전송 없음**
4. 멘토 검증은 실제 사람이 하나요? → 데모에서는 시뮬레이션
5. 결과를 어떻게 공유하나요? → HTML 리포트 다운로드
6. 여러 번 분석할 수 있나요? → 횟수 제한 없음, 3회부터 이력 분석 해금

## B3. 콘텐츠 원칙

- 본문 68ch 제한, 섹션 간 `--sp-section`
- **모든 더미 수치에는 "예시" 표기.** 근거 없는 숫자를 사실처럼 적지 않는다
- 실존 인물·기업을 사칭하지 않는다. 멘토 프로필은 가상임을 명시
