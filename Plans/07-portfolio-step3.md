## 2. ② 최종 점수 요약

3개 `StatTile` 가로 배열:

| 타일 | 값 | 라벨 |
|---|---|---|
| AI SCORE | `87` | 10대 원칙 자동 채점 |
| MENTOR SCORE | `82` | 현직 멘토 3인 검증 |
| **FINAL** | `85` | 가중 평균 (AI 50% + 멘토 50%) |

- FINAL은 `--t-impact`(700) — **이 페이지 유일한 700**
- 가중치는 `src/features/report/scoring.ts` 상수 1곳에서 관리
- 두 점수가 5점 이상 벌어지면 아래에 해석 문구를 붙인다: "AI는 시각 완성도를, 멘토는 문제 정의의 깊이를 더 중요하게 봤습니다."

## 3. ③ 원칙별 대조표 ★

이 리포트의 핵심. AI 점수와 사람의 관점을 **나란히** 놓는다.

```
┌────┬──────────────────┬──────────┬───────────────────────────┐
│ 01 │ 시각적 위계        │ ████ 9   │ 💬 멘토: 첫 페이지의 시선   │
│    │ Visual Hierarchy │          │    흐름이 특히 잘 잡혔습니다  │
├────┼──────────────────┼──────────┼───────────────────────────┤
│ 02 │ 레이아웃·그리드     │ ███  6   │ 💬 멘토: 3·4장에서 그리드가 │
│    │ Layout & Grid    │          │    흔들립니다               │
└────┴──────────────────┴──────────┴───────────────────────────┘
```

> ⚠️ 위 도식의 💬 는 이 문서 설명용이다. **실제 화면에는 이모지를 쓰지 않는다** (디자인 시스템 §Don't). 인라인 SVG 아이콘 또는 `MENTOR` 텍스트 라벨로 대체.

- 데스크톱: 4열 테이블 / 모바일: 원칙별 카드 스택
- 바 색: 8점 이상 `--primary`, 5–7 `--soft`, 4 이하 `--mute`
- AI와 멘토의 판단이 갈리는 항목은 `badge-pill` "관점 차이" 로 표시 — 리포트에서 가장 유용한 정보다
- 정렬 토글: 원칙 순서 / 점수 낮은 순

## 4. ④ 멘토 종합 코멘트

- 멘토 3인 카드 (`coaching-card`): 40px 모노톤 원형 아바타 + 이름 + 역할 + 코멘트
- 배경 `--soft`, 외곽선 없음, radius `--r-tile`

## 6. HTML 다운로드 ★

프롬프트 9번 — *"html 파일로 다운로드 받을 수 있게"*

### 6.1 요구 사항

**단일 파일로 완결되어야 한다.** 받은 사람이 인터넷 없이 더블클릭해도 똑같이 보여야 한다.

| 항목 | 처리 |
|---|---|
| CSS | 전량 `<style>` 인라인. 외부 참조 0 |
| 폰트 | **시스템 폰트 스택 사용** — woff2를 base64로 넣으면 파일이 2MB를 넘는다. 대신 `-apple-system, 'Malgun Gothic', sans-serif` 로 우아하게 폴백 |
| 이미지 | 포트폴리오 프리뷰 1장만 base64 인라인 (640px JPEG, ~150KB) |
| 로고 | AlignX SVG 인라인 |
| JS | **없음.** 정적 HTML만 |
| 색 | 라이트 모드 고정 (인쇄 대비) |

목표 파일 크기: **500KB 이하**.

### 6.2 구현

```ts
// src/features/report/buildHtml.ts
export function buildReportHtml(attempt: Attempt): string;   // 순수 함수 — 테스트 가능
```

- 문자열 템플릿으로 생성. **모든 사용자 입력은 이스케이프한다** (이름·주제·후기에 `<script>` 가 들어가도 안전해야 한다)
- `new Blob([html], { type: 'text/html;charset=utf-8' })` → `URL.createObjectURL` → `<a download>` → **`revokeObjectURL` 로 해제** (누락 시 메모리 누수)
- 파일명: `AlignX_리포트_{이름}_{YYYYMMDD}.html` — 한글 파일명은 브라우저별 처리가 다르므로 실제 다운로드로 검증
- `@media print` 규칙 포함 → 받은 HTML을 PDF로 인쇄 가능

### 6.3 리포트 HTML 내용

화면 ①~⑤와 동일한 정보 + 하단 푸터:

## 7. 완료 기준

- [ ] AI · 멘토 · 종합 3개 점수가 정확히 계산되어 표시
- [ ] 10개 원칙 전부 AI 점수 + 멘토 코멘트 대조 표시
- [ ] 2단계 요청사항 ↔ 멘토 답변이 인접 배치
- [ ] `[HTML 다운로드]` 클릭 → 파일 저장 → **오프라인·다른 기기에서 열어도 동일**
- [ ] 리포트 파일 500KB 이하, 외부 리소스 요청 0건 (개발자도구 Network로 확인)
- [ ] 이름에 `<script>alert(1)</script>` 를 넣어도 스크립트가 실행되지 않음
- [ ] 리포트 인쇄 미리보기가 A4에 정상 배치
- [ ] `revokeObjectURL` 호출 확인
- [ ] 화면 리포트가 라이트/다크 · 360/768/1440 전부 정상
- [ ] 3단계 미완료 회차로 직접 URL 진입 시 2단계로 리다이렉트
